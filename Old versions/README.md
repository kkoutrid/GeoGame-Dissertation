# Earlier versions

Earlier versions of GeoGame, kept to show how the project developed. None of
them are needed to play or build the current game.

| Folder | What it is |
|---|---|
| `Desktop/` | Earlier desktop versions (Geogame80 to Geogame91), the 2024 `Currentmodels` set, 2023 snapshots and older files |
| `Web/` | Earlier browser versions (GeogameWeb to GeogameWeb6) and a backup of the first WebAssembly attempt |
