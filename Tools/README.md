# Tools

Side projects that support the game. Players don't need any of them.

| File / folder | What it is |
|---|---|
| `email_backend_server.py`, `email_backend_server_v2.py`, `GameEmailProject/` | Small server that receives bug reports and level results from the game and forwards them by email. Its password is kept in a local `.env` file that is never uploaded. |
| `BotCreation/` | Experiments with training a bot to play the game |
| `extract_go.py` | Helper script used while converting the game to run in the browser |
